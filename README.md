# StudyFlow Timer

Планировщик занятий и отдыха для Windows с музыкальным мини-плеером, YouTube-вкладкой и Discord Rich Presence.

## Возможности

- Предметы по умолчанию: русский, история, английский, обществознание и математика.
- Можно добавлять свои предметы; список запоминается.
- Для занятия доступны таймеры от 10 минут до 4 часов с шагом 5 минут.
- Для отдыха доступны интервалы от 5 минут до 4 часов с шагом 5 минут.
- Очередь плана: например, «История — 30 мин → Отдых — 1 ч 40 мин → Математика — 50 мин».
- Автоматический переход к следующему пункту, звуки начала и окончания и уведомления Windows.
- Пауза, продолжение, пропуск, изменение порядка и удаление пунктов.
- Локальный плейлист: MP3, FLAC, WAV, OGG и другие форматы, если формат поддерживается мультимедийными декодерами Windows/Qt.
- Встроенная вкладка YouTube с возможностью открыть ссылку в стандартном браузере Windows.
- **Discord Rich Presence:** текущий предмет или отдых, автоматический таймер оставшегося времени, следующий пункт плана и его длительность, настраиваемая картинка.
- Очередь, список предметов, музыкальный плейлист и настройки Discord сохраняются между запусками.

## Discord Rich Presence: первая настройка

1. Установи и запусти **настольный Discord** на компьютере. Rich Presence через локальный RPC не работает с одной только веб-версией Discord.
2. Открой [Discord Developer Portal](https://discord.com/developers/applications) и создай приложение, например `StudyFlow Timer`.
3. В разделе **General Information** скопируй **Application ID**.
4. Запусти StudyFlow Timer и нажми кнопку **Discord Activity ⚙** в верхней части окна.
5. Включи Rich Presence, вставь Application ID и нажми «Save». После подключения статус приложения появится в Discord.
6. Чтобы добавить отдельную картинку в большую область активности, открой настройки своего приложения в Developer Portal, найди раздел **Rich Presence / Art Assets**, загрузи и сохрани изображение, затем впиши его **asset key** в поле «Ключ большой иконки». Ключи изображений Discord нормализует в нижний регистр. Поле можно оставить пустым, пока иконка не подготовлена.

### Что увидят друзья в Discord

- **Имя приложения:** StudyFlow Timer.
- **Основная строка:** `Сейчас: История` или `Сейчас: отдых`.
- **Таймер:** когда пункт выполняется, Discord получает время окончания и сам отображает обратный отсчёт. Когда таймер на паузе, оставшееся время показывается текстом.
- **Следующая строка:** например, `Далее: Отдых — 1 ч 40 мин`.
- **Картинка:** asset key из настроек Discord Developer Portal, если он указан.

Активность обновляется при запуске и завершении пункта, паузе/продолжении, а также при изменении очереди. Подключение выполняется в отдельном потоке, поэтому закрытый Discord не должен замораживать таймер приложения. Если Discord был закрыт, программа пытается переподключиться автоматически.

## Самый простой запуск из исходников

1. Установи Python 3.11 или 3.12 для Windows с сайта https://www.python.org/downloads/windows/ . При установке отметь **Add Python to PATH**.
2. Распакуй папку `StudyFlow_Timer` в удобное место.
3. Открой папку, щёлкни адресную строку Проводника, напечатай `cmd` и нажми Enter.
4. Выполни команды:

   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install --upgrade pip
   py -m pip install -r requirements.txt
   py main.py
   ```

## Сборка в EXE

Дважды щёлкни `build_exe.bat`. Скрипт установит необходимые библиотеки и соберёт приложение. По завершении файл будет здесь:

`dist\StudyFlowTimer\StudyFlowTimer.exe`

Сборка использует режим папки, потому что Qt WebEngine требует вспомогательные файлы. Не перемещай EXE отдельно от этой папки. Перед повторной сборкой закрой запущенную программу. Собирать нужно на Windows; рекомендуется Python 3.11 или 3.12 x64.

## Как пользоваться таймером

1. Выбери предмет и длительность, затем нажми **Добавить**.
2. Чтобы вставить отдых между занятиями, выбери **Отдых** и добавь его в нужное место.
3. Расставь пункты очереди кнопками **Выше** / **Ниже**.
4. Нажми **Старт**. После завершения каждого пункта программа начнёт следующий автоматически.
5. Чтобы слушать локальную музыку, добавь файлы во вкладке **Локальные файлы**. Чтобы использовать YouTube, открой соответствующую вкладку и нажми Play на самой странице.

## Примечания

- Окно программы должно оставаться запущенным, чтобы таймер продолжал идти.
- Настройки приложения и очередь сохраняются в папке данных приложения Windows.
- Discord Rich Presence требует настольный клиент Discord, валидный Application ID и разрешённое отображение активности в настройках Discord.
- Для собственной картинки её нужно загрузить в Art Assets соответствующего Discord-приложения. Путь к локальному файлу на компьютере нельзя использовать вместо asset key.
- Windows Toast-уведомления зависят от системных настроек уведомлений Windows.
- Воспроизведение YouTube во встроенном Qt WebEngine может зависеть от совместимости сайта и имеющихся кодеков; кнопка «В обычном браузере» открывает ссылку в установленном браузере Windows.
